    Développer une API avec Django Rest Framework

    Une API (Application Programming Interface) permet à différentes applications de communiquer entre elles en échangeant des données, généralement au format JSON.

    1. Pourquoi utiliser DRF ?

    Alors que Django classique renvoie du HTML, DRF transforme vos modèles Python en données structurées.

    • Sérialisation puissante : Conversion automatique des objets complexes en JSON.
    • Interface de navigation : Une interface web pour tester vos points d'entrée (endpoints) directement dans le navigateur.
    • Authentification : Gestion native des tokens (Jetons), OAuth2, etc.

    2. Installation et Configuration

    Dans votre environnement virtuel :

    pip install djangorestframework

    Dans votre fichier settings.py :

    INSTALLED_APPS = [
    ...
    'rest_framework',
    'blog', # Votre application
]

    3. Le concept de Sérialiseur (Serializer)

    C'est le cœur de DRF. Il définit comment transformer un objet Post en JSON. Créez un fichier blog/serializers.py :

    from rest_framework import serializers
from .models import Post

class PostSerializer(serializers.ModelSerializer):
    class Meta:
        model = Post
        fields = ['id', 'titre', 'contenu', 'auteur', 'date_publication']

    4. Les Vues API (APIViews)

    Il existe plusieurs façons de créer des vues dans DRF. La plus simple et la plus complète pour les débutants est d'utiliser les ModelViewSet. Dans blog/views.py :

    from rest_framework import viewsets
from .models import Post
from .serializers import PostSerializer

class PostViewSet(viewsets.ModelViewSet):
    """
    Cette vue fournit automatiquement les actions 'list', 'create', 
    'retrieve', 'update' et 'destroy'.
    """
    queryset = Post.objects.all().order_by('-date_publication')
    serializer_class = PostSerializer

    5. Le Routage (Routers)

    DRF utilise des "Routers" pour générer automatiquement les URLs de l'API. Dans mysite/urls.py :

    from django.urls import path, include
from rest_framework.routers import DefaultRouter
from blog.views import PostViewSet

router = DefaultRouter()
router.register(r'posts', PostViewSet)

urlpatterns = [
    path('api/', include(router.urls)),
]

    6. Tester l'API

    Une fois le serveur lancé (python manage.py run server), rendez-vous sur : http://127.0.0.1:8000/api/posts/

    Vous y trouverez l'interface "Browsable API" de DRF où vous pouvez :

    • GET : Voir la liste des articles.
    • POST : Créer un nouvel article via un formulaire JSON.
    • PUT/PATCH : Modifier un article via son ID (ex: /api/posts/1/).
    • DELETE : Supprimer un article.

    7. Sécuriser l'API (Permissions)

    Par défaut, l'API est ouverte. Pour restreindre l'accès, modifiez votre PostViewSet :

    from rest_framework import permissions

class PostViewSet(viewsets.ModelViewSet):
    ...
    # Seuls les utilisateurs connectés peuvent modifier, les autres lisent seulement.
    permission_classes = [permissions.IsAuthenticatedOrReadOnly]

    A retenir :

    1. Serializer : Le traducteur (Modèle ↔ JSON).
    2. ViewSet : Le cerveau (Logique de traitement).
    3. Router : Le GPS (Génération des URLs).
    4. JSON : La langue universelle de l'API.
