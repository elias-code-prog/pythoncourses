    Projet : Création d'un Blog avec Django

    Étape 1 : Initialisation du projet

    On commence par créer l'environnement et la structure de base.

    # Créer et activer l'environnement virtuel
# Mac/Linux
python3 -m venv .venv
source .venv/bin/activate  
#Windows
python -m venv .venv
     ./venv/Scripts/Activate.Ps1

# Installer Django et créer le projet
#Windows
pip install django
django-admin startproject mysite .
python manage.py startapp blog

# Mac/Linux
pip3 install django
django-admin startproject mysite .
python3 manage.py startapp blog

    N'oubliez pas d'ajouter 'blog', dans la liste INSTALLED_APPS du fichier settings.py.

    Étape 2 : Le Modèle (La Base de Données)

    Un article de blog (Post) a besoin de plusieurs caractéristiques. Dans blog/models.py :

    from django.db import models
from django.utils import timezone

class Post(models.Model):
    titre = models.CharField(max_length=200)
    contenu = models.TextField()
    date_publication = models.DateTimeField(default=timezone.now)
    auteur = models.ForeignKey('auth.User', on_delete=models.CASCADE)

    def __str__(self):
        return self.titre

    Action : Créez les tables avec python manage.py makemigrations puis python manage.py migrate.

    Étape 3 : L'Interface Admin

    Pour créer des articles sans coder de formulaire tout de suite, utilisez l'outil intégré de Django. Dans blog/admin.py :

    from django.contrib import admin
from .models import Post

admin.site.register(Post)

    Créez un compte administrateur avec python manage.py createsuperuser pour tester.

    Étape 4 : Les URLs (L'Aiguillage)

    Il faut dire à Django quelle page afficher selon l'adresse demandée.

    1. **Dans mysite/urls.py** : Redirigez vers l'application blog.
    path('', include('blog.urls')),
    1. **Dans blog/urls.py** (à créer) :
    from django.urls import path
from . import views

urlpatterns = [
    path('', views.post_list, name='post_list'),
    path('post/<int:pk>/', views.post_detail, name='post_detail'),
]

    Étape 5 : La Vue (La Logique)

    La vue va chercher les articles dans la base de données et les envoie au template. Dans blog/views.py :

    from django.shortcuts import render, get_object_or_404
from .models import Post

def post_list(request):
    posts = Post.objects.all().order_by('-date_publication')
    return render(request, 'blog/post_list.html', {'posts': posts})

def post_detail(request, pk):
    post = get_object_or_404(Post, pk=pk)
    return render(request, 'blog/post_detail.html', {'post': post})

    Étape 6 : Le Template (L'Affichage)

    Créez un dossier blog/templates/blog/ et un fichier post_list.html.

    <h1>Mon Super Blog</h1>
{% for post in posts %}
    <article>
        <h2><a href="{% url 'post_detail' pk=post.pk %}">{{ post.titre }}</a></h2>
        <p>Publié le : {{ post.date_publication }} par {{ post.auteur }}</p>
        <p>{{ post.contenu|truncatechars:100 }}</p>
    </article>
    <hr>
{% endfor %}

    Étape 7 : Design et Mise en page (Héritage)

    le principe DRY avec un fichier base.html.

    • base.html contient la structure (Navbar, Footer).
    • Les autres pages utilisent {% extends 'blog/base.html' %} pour s'y insérer.

    A retenir

    1. Migration : Transformer du code Python en table SQL.
    2. ORM : Récupérer des données (Post.objects.all()).
    3. Routing : Créer des URLs dynamiques avec des ID (<int:pk>).
    4. Templating : Afficher des données avec des boucles Jinja2.
