## Documentations Officielles (Les Bibles)


* **[Documentation Python](https://docs.python.org/fr/3/)** : Disponible en français, elle est extrêmement complète, bien que parfois dense.
* **[Documentation Django](https://docs.djangoproject.com/fr/stable/)** : Considérée comme l'une des meilleures documentations au monde. Le "Tutoriel de la boîte de sondage" est un passage obligé.



## Outils de Développement (Le "Stack")

| Outil | Usage | Pourquoi l'utiliser ? |
| --- | --- | --- |
| **VS Code** | Éditeur de code | Le standard actuel avec d'excellentes extensions Python/Django. |
| **DB Browser for SQLite** | Base de données | Pour voir visuellement ce qu'il y a dans votre fichier `db.sqlite3`. |
| **Postman** | API | Très utile si vous commencez à faire du Django Rest Framework. |
| **Python Tutor** | Visualisation | Génial pour voir comment Python exécute le code ligne par ligne. |

## Tutoriels et Apprentissage Continu

* **[Django Girls Tutorial](https://tutorial.djangogirls.org/fr/)** : Malgré son nom, il est destiné à tout le monde. C'est sans doute le guide le plus pédagogique et le plus clair pour débuter de zéro jusqu'au déploiement.
* **[TestDriven.io](https://testdriven.io/)** : Pour ceux qui veulent passer au niveau supérieur (Docker, Microservices, Tests automatisés).
* **[Real Python](https://realpython.com/)** : Des articles d'une qualité exceptionnelle sur des points précis de Python.

## Communautés et Entraide

Apprendre à poser des questions est un art.

* **[Stack Overflow](https://stackoverflow.com/questions/tagged/django)** : Le premier réflexe en cas d'erreur. Astuce : Toujours chercher en anglais pour avoir 10x plus de résultats.
* **[Forum Django (Français)](https://www.django-fr.org/)** : Une communauté francophone active pour ceux qui sont moins à l'aise avec l'anglais.
* **Discord / Slack** : De nombreux serveurs comme "Python Discord" permettent de discuter en direct avec des développeurs du monde entier.

##  Prochaines étapes

Transformer mes étudiants en développeurs employables, voici le parcours conseillé après ce cours :

1. **Le Déploiement** : Apprendre à mettre le site en ligne (sur Railway, Render, ou PythonAnywhere).
2. **Les API** : Découvrir **Django Rest Framework (DRF)** pour connecter Django à une application mobile ou un framework JS (React/Vue).
3. **Les Tests** : Apprendre à écrire des tests pour s'assurer que le site ne casse pas à chaque mise à jour.
